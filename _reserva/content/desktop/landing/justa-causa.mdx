# Justa Causa Indevida: Pode Reverter e Receber Tudo

**Justa causa é a pena máxima.** Só cabe para faltas **graves, provadas, proporcionais e imediatas**. Muitas são indevidas.

---

## O que a lei exige para justa causa (Art. 482 CLT)

| Falta grave | Exemplo |
|-------------|---------|
| Ato de improbidade | Furto, desvio, fraude |
| Incontinência de conduta | Assédio sexual, atos libidinosos |
| Condenação criminal | Transitada em julgado |
| Desídia | Repetidos descuidos, negligência |
| Embriaguez | Habitual ou em serviço |
| Violação de segredo | Dados confidenciais da empresa |
| Insubordinação | Recusa a ordem direta e legal |
| Abandono de emprego | >30 dias sem justificativa |
| Ofensa física | Agressão a colegas/chefes |
| Jogos de azar | No local de trabalho |
| Perda de habilitação | Profissional (motorista, piloto) |

---

## Requisitos OBRIGATÓRIOS (todos devem existir)

| Requisito | O que significa |
|-----------|-----------------|
| **Gravidade** | Falta grave (não leve/leve) |
| **Prova** | Empresa deve provar (não basta alegar) |
| **Proporcionalidade** | Pena deve caber na falta (1 atraso ≠ justa causa) |
| **Imediatidade** | Aplicada logo após a falta (não meses depois) |
| **Simultaneidade** | Não pode punir 2x pela mesma falta |

---

## Quando costuma ser INDEVIDA

| Situação | Por que costuma ser indevida |
|----------|------------------------------|
| **1 atraso / 1 falta** | Falta leve, não grave |
| **Desempenho baixo** | Não é falta grave (pode ser capacitação) |
| **Briga isolada** | Não é habitual (pode ser advertência) |
| **Crítica ao chefe** | Liberdade de expressão (respeitosa) |
| **Recusa a ordem ilegal/perigosa** | Não é insubordinação |
| **Doença não comunicada a tempo** | Falta justificada (atestado) |
| **Desempenho baixo após assédio** | Causa = assédio, não desídia |

---

## Se a justa causa for revertida

**Vira demissão SEM justa causa** = você recebe **TUDO**:

| Verba | Valor |
|-------|-------|
| Saldo de salário | Dias trabalhados no mês |
| Aviso prévio | 30 a 90 dias (indenizado) |
| 13º proporcional | 1/12 por mês trabalhado |
| Férias vencidas + 1/3 | Se não tirou |
| Férias proporcionais + 1/3 | 1/12 por mês do período |
| FGTS + 40% | Saldo + multa 40% |
| Seguro-desemprego | Guias para saque |
| Multa art. 477 | 1 salário se pagou fora do prazo |
| **Indenização por danos morais** | Se justa causa foi vexatória/vexatória |

---

## Como reverter

1. **Peça a carta de justa causa** por escrito (tem direito)
2. **Não assine** concordando se discorda
3. **Junte provas** de que a falta não existia ou era leve
4. **Procure advogado urgente** — ação de reversão de justa causa
5. **Peça liminar** para receber verbas urgentes

---

## Prazos

- **Ação de reversão**: 2 anos após a demissão
- **Não assine** concordando com a justa causa
- **Não peça demissão** por conta própria
